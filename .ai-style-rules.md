# LShorter — AI Style & Architecture Rules (`.ai-style-rules.md`)

> Generated via ECC `inherit-legacy-style` & design governance.

## [Golden Files]
- `app/globals.css` — Canonical theme system (Dark `#09090b` / `#141416` & Light Crème Latte `#faf7f2` / `#fffdf9`, Cyber Blue `#0066ff` mobile `<768px`, Warm Orange `#ff6600` desktop `>=768px`, strict `--radius: 10px`).
- `components/dashboard/populated-state.tsx` — Dashboard Overview layout, KPI cards, Links Data Grid, and Customers & API Conversions Data Grid.
- `app/(dashboard)/dashboard/links/page.tsx` — Links Data Grid (`@reui/c-data-grid-10`) with Banner / DiceBear `glass` avatars, Smart Routing & A/B active badges, and quota bars.
- `app/(dashboard)/dashboard/analytics/page.tsx` — Analytics Funnel, Smart Routing / A/B split, and Live Visitors & Conversions Data Grid.

## [Naming & State-Control Rules]
1. **Strict 10px Border Radius**:
   - Every card, container, modal, popover, input, button, and Data Grid wrapper MUST use **`rounded-[10px]`** (or `.rounded-saas` / `border-radius: 10px`). Never use `rounded-2xl`, `rounded-3xl`, or `rounded-[14px]` on containers.
2. **Theme Compliance (`app/globals.css`)**:
   - Always use `bg-[#141416]`, `bg-[#18181b]`, `border-[#222225]`, `border-[#27272a]`, and `text-neutral-100` / `text-neutral-300` / `text-neutral-400` so Light Mode (`html.light`) and Dark Mode (`html:not(.light)`) adapt automatically via `app/globals.css`.
3. **Avatars & Link Banners (DiceBear `glass`)**:
   - Customer / Visitor Avatar fallback: `https://api.dicebear.com/9.x/glass/svg?seed=${encodeURIComponent(seed)}`
   - Link Banner (`ogImage`) fallback in Data Grids: When `link.ogImage` is empty, dynamically render `https://api.dicebear.com/9.x/glass/svg?seed=${encodeURIComponent(link.slug || link.targetUrl)}`.
4. **Cloudflare D1 Quota Protection**:
   - Never add unindexed `OR` subqueries or `window.focus` cache invalidation loops. Use single indexed queries and `lib/cloudflare-api.ts` in-memory caching.

## [DONTs]
- **DONT** use `rounded-xl` (`12px`), `rounded-2xl` (`16px`), or `rounded-3xl` (`24px`) on dashboard cards, tables, or popups — strictly keep `10px` (`rounded-[10px]`).
- **DONT** use `text-zinc-*` without `globals.css` light-mode mappings; use `text-neutral-*` or `var(--foreground)`.
- **DONT** use `npm` or `npx` in terminal commands; always use `pnpm` / `pnpm dlx`.
